# نظرة معمارية على النظام

يوضح هذا المستند بنية نظام الموارد البشرية الحكومي المبني على ASP.NET Core MVC.

## الطبقات الرئيسية
- **العرض (Presentation):** Views وControllers لتقديم واجهة عربية تدعم الاتجاه من اليمين لليسار، وتوفر تجربة استخدام موحدة لموظفي الموارد البشرية.
- **الخدمات (Services):** واجهة `IEmployeeService` و `ILookupService` لعزل منطق الأعمال عن طبقة العرض وتسهيل الاختبار.
- **البيانات (Data):** سياق `ApplicationDbContext` باستخدام Entity Framework Core مع SQL Server، ويتضمن تكوينات العلاقات بين الكيانات.
- **النماذج (Models):** تعريف كيانات الموارد البشرية مثل الموظفين والدوائر والإجازات والرواتب والتدريب.

## الأمن والصلاحيات
- تم تفعيل ASP.NET Core Identity لإدارة المستخدمين والأدوار.
- يتم حماية لوحة القيادة ومعظم الشاشات بـ `[Authorize]` مع تحديد أدوار مختلفة (مشرف، مدير موارد بشرية، مالية، إلخ).

## تكاملات مستقبلية
- **نظام المراسلات الحكومية:** لربط الوثائق الصادرة والواردة مع ملف الموظف.
- **بوابة الخدمة الذاتية:** تطوير واجهات واجهات برمجة تطبيقات (APIs) تسمح للموظفين بإرسال الطلبات وتتبعها.
- **خدمات بريد إلكتروني وSMS:** لإرسال التنبيهات بالقرارات الإدارية.

## البنية التحتية المقترحة للنشر
1. **بيئة التطبيقات:** خادم Windows أو Linux يعمل عليه Kestrel خلف IIS أو Nginx.
2. **قاعدة البيانات:** SQL Server مهيأ بتوافر عالٍ (Always On) لضمان الاستمرارية.
3. **النسخ الاحتياطي:** خطط نسخ احتياطي يومية وقواعد الاحتفاظ بالبيانات وفقًا لتعليمات ديوان الرقابة المالية.
4. **المراقبة:** دمج Application Insights أو System Center لمراقبة الأداء وسجلات التدقيق.
