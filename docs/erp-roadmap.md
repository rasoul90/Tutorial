# خارطة طريق نظام الـ ERP الحكومي العراقي

هذه الوثيقة توضح التصور الشامل لتطوير نظام تخطيط موارد المؤسسات (ERP) متكامل للمؤسسات الحكومية العراقية بما يتوافق مع التشريعات المحلية وخطة التحول الرقمي. تعتمد الخارطة على التقسيم المرحلي، إدارة المخاطر، وضمان الامتثال القانوني والأمني منذ البداية.

## 1. المبادئ التوجيهية
- **الامتثال القانوني:** الالتزام بقانون الخدمة المدنية رقم 24 لسنة 1960 المعدل، قانون الملاك، التعليمات المالية رقم 1 لسنة 2007، تعليمات الموازنة الاتحادية السنوية، وتعليمات الأرشفة الحكومية.
- **الحوكمة الرقمية:** اتباع استراتيجية التحول الرقمي الحكومية (2021-2025)، مع اعتماد بنية معيارية وخدمات قابلة لإعادة الاستخدام.
- **الأمن السيبراني:** تطبيق معايير الجهاز الوطني للأمن السيبراني، وتبني ضوابط ISO/IEC 27001، وتشفير البيانات الحساسة.
- **اللغة المحلية وواجهة RTL:** دعم اللغة العربية (Iraq Arabic) والاتجاه من اليمين إلى اليسار، بالإضافة إلى إمكانية الترجمة إلى الكردية والإنجليزية.
- **القابلية للتوسع والتكامل:** واجهات برمجية (APIs) معيارية وفق REST/JSON وOpenAPI لربط الأنظمة القائمة (السجل المدني، الرواتب المركزية، المالية الاتحادية).

## 2. النطاق الوظيفي
1. **إدارة الموارد البشرية:** بيانات الخدمة، الترقيات، العلاوات، العقوبات، سجلات الدوام، الإجازات، الرواتب، التقاعد.
2. **إدارة المالية والموازنة:** إعداد الموازنات السنوية، تنفيذ الصرف، إدارة السلف والأمانات، السجلات المحاسبية وفق النظام المحاسبي الموحد، التقارير المالية الرسمية.
3. **المشتريات والعقود:** العطاءات، الإحالة، العقود، متابعة التنفيذ، الالتزام بقانون العقود الحكومية رقم 87 لسنة 2004.
4. **إدارة الأصول والمخازن:** مراقبة الأصول الثابتة، الجرد، الاستهلاك، إدارة المخزون وفق تعليمات المخازن الحكومية.
5. **الخدمات اللوجستية والدعم:** الأسطول، الصيانة، إدارة المراسلات، مركز خدمة المواطن.
6. **حوكمة البيانات والتقارير:** مستودع بيانات حكومي، مؤشرات الأداء، تكامل مع Power BI وSSRS.
7. **إدارة المخاطر والامتثال:** سجلات التدقيق، تتبع الالتزام، خطط استمرارية الأعمال.

## 3. الهندسة التقنية المقترحة
- **الطبقات:**
  - **العرض (Presentation):** ASP.NET Core MVC وBlazor للأدوات التفاعلية، تطبيقات جوال مستقبلية باستخدام MAUI.
  - **الخدمات (Service Layer):** ASP.NET Core Web API، حوكمة الهوية عبر Azure AD B2C أو هوية حكومية محلية، دعم OAuth2/OpenID Connect.
  - **البيانات (Data Layer):** SQL Server 2019/2022، مستودع بيانات عبر Azure Synapse أو SQL Server DW، مخزن وثائق (SharePoint أو FileNet).
  - **التكامل (Integration):** حافلة رسائل (Service Bus)، دعم تبادل البيانات عبر ESB حكومي، تكامل مع الأنظمة المالية المركزية.
- **البنية السحابية/المختلطة:** اعتماد Azure Stack أو مركز بيانات حكومي، مع مراعاة قوانين حماية البيانات.
- **قابلية التوسع:** استخدام Kubernetes أو Azure App Service لنشر الخدمات المصغرة عند الحاجة.
- **المراقبة والتدقيق:** Azure Monitor، Elastic Stack، ونظام تدقيق داخلي مخصص.

## 4. خارطة الطريق المرحلية
| المرحلة | المدة التقديرية | المخرجات الرئيسية |
|---------|-----------------|-------------------|
| التحضير والتحليل | 3 أشهر | تحليل فجوة الإجراءات الحالية، جمع المتطلبات القانونية، إعداد خطة إدارة التغيير. |
| التصميم التفصيلي | 3 أشهر | نماذج بيانات، مخططات العمليات (BPMN)، تصميم تجربة المستخدم، خطة التكامل. |
| التطوير الأساسي | 6 أشهر | بناء وحدات الموارد البشرية والمالية، واجهات API، لوحات القيادة الأساسية. |
| التكامل والتوسع | 4 أشهر | ربط الأنظمة الخارجية (السجلات المدنية، الرواتب)، أتمتة سير العمل، التقارير المتقدمة. |
| الاختبارات والاعتماد | 3 أشهر | اختبارات قبول المستخدم، اختبارات الأداء والاختراق، إصدار دليل المستخدم. |
| الإطلاق والتدريب | 2 أشهر | تدريب فرق الموارد البشرية والمالية، خطة الدعم، تقييم ما بعد الإطلاق. |
| التحسين المستمر | مستمر | تحسينات دورية، تحديثات أمنية، تكامل وحدات جديدة. |

## 5. إدارة البيانات والامتثال
- **سياسات الأرشفة:** الاحتفاظ بسجلات الخدمة وفق تعليمات الأرشيف الوطني، تخزين النسخ الرقمية في مستودع آمن.
- **حماية البيانات الشخصية:** إخفاء الهوية عند مشاركة البيانات، استخدام تشفير على مستوى الصفوف والأعمدة في SQL Server، إدارة المفاتيح عبر HSM.
- **التدقيق الداخلي:** مسارات تدقيق تفصيلية لكل عملية، تقارير امتثال دورية إلى ديوان الرقابة المالية وهيئة النزاهة.
- **استمرارية الأعمال:** نسخ احتياطية يومية، مواقع تعافي من الكوارث، اختبارات DR نصف سنوية.

## 6. إدارة التغيير والتدريب
- برنامج تدريبي متعدد المراحل يشمل مدراء الموارد البشرية، مسؤولي المالية، ووحدات تقنية المعلومات.
- مواد تدريب إلكترونية (LMS)، جلسات حضورية، ودليل استخدام عربي مفصل.
- خطة اتصال لإشراك أصحاب المصلحة وتعزيز قبول النظام.

## 7. خطة الحوكمة
- لجنة توجيهية برئاسة ممثل من الأمانة العامة لمجلس الوزراء.
- مكتب مشروع (PMO) يستخدم منهجية PRINCE2 أو PMBOK.
- آلية لإدارة الطلبات والتغييرات مع تقييم أثرها على الامتثال والميزانية.

## 8. التكامل مع النظام الحالي
- ربط مع نظام الرواتب الموحد، نظام البطاقة الوطنية الموحدة، نظام المراسلات الإدارية.
- واجهات برمجية لتبادل البيانات مع وزارة المالية، وزارة التخطيط، وديوان الخدمة المدنية.
- دعم التوقيع الإلكتروني المعتمد وفق تعليمات وزارة الاتصالات.

## 9. خارطة المخاطر
- **تشريعات متغيرة:** إنشاء فريق امتثال لمتابعة القوانين وتحديث النظام.
- **مقاومة التغيير:** تنفيذ برامج إدارة التغيير والتواصل.
- **الأمن السيبراني:** اختبارات اختراق، تحديثات دورية، إدارة ثغرات.
- **تكامل الأنظمة القديمة:** استخدام طبقات تكامل معزولة، وخطة لتحديث البيانات تدريجياً.

## 10. مؤشرات الأداء الرئيسية (KPIs)
- وقت إنجاز معاملة الموارد البشرية (قبل/بعد).
- نسبة الالتزام بجداول الرواتب.
- نسبة اكتمال بيانات الموظفين.
- مستوى رضى المستخدم النهائي.
- عدد الحوادث الأمنية المكتشفة والمعالجة.

## 11. الخطوات التالية المقترحة للمستودع
1. تقسيم الحل الحالي إلى وحدات (HR، مالية، مشتريات، أصول) مع مشاريع مستقلة وطبقة خدمات مشتركة.
2. إضافة طبقة هوية (IdentityServer أو Azure AD) مع أدوار وصلاحيات مفصلة حسب التشريعات.
3. إعداد بنية هجرات EF Core وتهيئة بيانات أولية (Seed Data) وفق القوانين (سلم الرواتب، الدرجات الوظيفية، العلاوات).
4. تصميم واجهات برمجية للتكامل مع الأنظمة الحكومية.
5. بناء أتمتة سير عمل باستخدام Power Automate أو Camunda لدعم إجراءات الموارد البشرية.
6. إعداد اختبارات وحدات وتكامل، وخط أنابيب CI/CD للنشر الحكومي.

> هذه الخارطة تعد نقطة انطلاق عملية لتوسيع النظام الحالي ليصبح نظام ERP متكامل يخدم المؤسسات الحكومية العراقية ضمن إطار التحول الرقمي.
