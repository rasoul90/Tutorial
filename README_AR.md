# Ultra Audit Services (UAS)

## نظرة عامة
Ultra Audit Services (UAS) هو نظام تحليلات تدقيق وأوراق عمل مصمم للرقابة المالية الحكومية. يوفّر تجربة مشابهة لـ ACL Analytics وCaseWare IDEA مع دعم كامل للغات العربية والإنجليزية واتجاه RTL.

## تشغيل محليًا
1. تأكد من وجود SQL Server.
2. حدّد سلسلة الاتصال في `src/UltraAudit.Web/appsettings.json`.
3. تشغيل التطبيق:
   - `dotnet run --project src/UltraAudit.Web`

## خطوات إنشاء قاعدة البيانات
- يستخدم النظام EF Core بنهج Code-First.
- عند التشغيل، يتم تطبيق الهجرات تلقائيًا عبر `Database.Migrate()`.
- يمكن إضافة هجرة جديدة من خلال:
  - `dotnet ef migrations add InitialCreate --project src/UltraAudit.Infrastructure --startup-project src/UltraAudit.Web`

## الوحدات والتنقل
- لوحة التحكم، المشاريع، البيانات، التحليلات، الاستثناءات، أوراق العمل، التقارير، رؤى الذكاء الاصطناعي، الإدارة.
- القائمة الجانبية تتبع الهيكل المطلوب بدقة داخل واجهة UAS.

## أوامر التحليلات
- كتالوج أوامر يغطي التحضير، التحقيق، العينات، الحسابات، والتصدير.
- كل أمر يحتوي على الاسم، الفئة، الوصف، ومخطط معلمات JSON.
- التشغيل يولّد AnalysisRun ثابتًا مع بصمة تكامل لضمان عدم العبث.

## RBAC + ACL
- الأدوار تُدار عبر Identity.
- صلاحيات ACL تعتمد على منح صلاحيات للمورد (مشروع/مجموعة بيانات/تحليل/تشغيل/استثناء/تقرير/ورقة عمل).
- يتم التحقق من الصلاحيات قبل تنفيذ العمليات الحساسة.

## التعريب و RTL
- يستخدم النظام IStringLocalizer وملفات resx.
- يتوفر محوّل لغة في الشريط العلوي.
- عند اختيار العربية يتم تحميل ملف `rtl.css` مع تعيين اتجاه النص RTL.

## ملاحظات الأمن
- رفع الملفات يتم عبر سياسة سماح للامتدادات.
- الأدلة تخزن خارج قاعدة البيانات مع عزل لكل مشروع.
- جميع العمليات الحساسة يتم تسجيلها في سجل التدقيق.
