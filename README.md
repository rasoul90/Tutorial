# نظام إدارة الموارد البشرية الحكومي (Iraq Gov HR)

هذا المستودع يحتوي على نواة نظام موارد بشرية موجه لمؤسسة حكومية عراقية باستخدام **ASP.NET Core MVC** مع **قاعدة بيانات SQL Server**. يهدف النظام إلى إدارة دورة حياة الموظف بدءًا من التعيين وحتى التقاعد، مع توفير لوحة معلومات تنفيذية، وإدارة الرواتب، والإجازات، والتقييمات، والتدريب.

## المزايا الرئيسية
- إدارة بيانات الموظفين مع ربطهم بالدوائر والمناصب.
- تتبع طلبات الإجازة مع مسار الموافقات.
- إدارة سجلات الرواتب مع حساب الرواتب الصافية.
- إدارة تقييم الأداء وخطط التطوير.
- تنظيم البرامج التدريبية ومتابعة المشاركين.
- واجهة باللغة العربية ودعم للاتجاه من اليمين إلى اليسار.

## المتطلبات
- .NET 6 SDK أو أعلى.
- SQL Server 2019 أو أعلى (يمكن استخدام SQL Server Express).
- أداة إدارة سرية لتخزين سلسلة الاتصال (مثل Secret Manager أو Azure Key Vault) عند النشر.

## الإعداد المحلي
1. قم بتحديث سلسلة الاتصال في `appsettings.json` أو استخدم [Secret Manager](https://learn.microsoft.com/aspnet/core/security/app-secrets) لتعريف قيمة `ConnectionStrings:DefaultConnection`.
2. نفّذ أوامر الهجرة (بعد إنشاء الهجرات) لتجهيز قاعدة البيانات:
   ```bash
   dotnet tool restore
   dotnet ef database update
   ```
3. شغّل التطبيق:
   ```bash
   dotnet run --project src/HRGov.HRApp/HRGov.HRApp.csproj
   ```
4. افتح المتصفح على `https://localhost:5001` لمعاينة النظام.

> **ملاحظة:** تم تضمين نموذج تصميمي (Skeleton) للمشروع يمكن البناء عليه وتوسيعه حسب احتياجات المؤسسة، بما في ذلك الهوية، الصلاحيات، وتقارير Power BI أو SSRS مستقبلًا.

## تنزيل ملفات المشروع
يمكنك الحصول على نسخة مضغوطة من المشروع لمشاركتها أو تنزيلها كما يلي:

1. تأكد من تثبيت Git على الجهاز الذي تشغِّل عليه هذا المستودع.
2. نفّذ الأمر التالي من جذر المستودع لإنشاء ملف ‎ZIP‎ داخل المجلد `dist/`:
   ```bash
   ./scripts/package-project.sh
   ```
   - يمكنك تمرير قيمة اختيارية (مثل رقم الإصدار) لإضافتها إلى اسم الملف:
     ```bash
     ./scripts/package-project.sh v1.0.0
     ```
3. سيظهر المسار الكامل للملف الناتج في المخرجات، ويمكنك نقله أو تحميله كما تشاء.

> في حال رغبتك بتنزيل المشروع مباشرةً من GitHub دون تشغيل السكربت، يمكنك استخدام زر **Download ZIP** أو تنفيذ:
> ```bash
> git clone https://github.com/<your-org>/HRGov.git
> ```

## خطوات مستقبلية مقترحة
- إضافة طبقة هجرات EF Core وتهيئة بيانات أولية (Seed Data).
- ربط النظام بخدمة الهوية الوطنية للمصادقة الأحادية (SSO) إن توفر ذلك.
- بناء تقارير ولوحات Power BI لمراقبة مؤشرات الأداء.
- أتمتة إجراءات الموارد البشرية (Workflow) باستخدام Power Automate أو Logic Apps.
- الاطلاع على [خارطة طريق نظام الـ ERP الحكومي](docs/erp-roadmap.md) لتوسيع النواة الحالية إلى منصة متكاملة متوافقة مع خطة التحول الرقمي العراقية.
